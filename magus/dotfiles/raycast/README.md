# Raycast setup

Ported from Machinist / Athanor. Apply these choices inside Raycast; Magus does not modify its private settings database or install extensions automatically.

- **Replace Spotlight:** choose Command-Space as Raycast's hotkey. Release the same shortcut in macOS Spotlight settings first.
- **Clipboard History:** enable it and choose a shortcut such as Command-Shift-V. Review retention and excluded apps before using it.
- **Snippets:** add reusable text expansions. Keep personal snippets out of shared presets.
- **Hyper Key:** optionally map Caps Lock to Control-Option-Command-Shift; review existing keyboard mappings first.
- **Declutter Root Search:** disable commands you never use.
- **Auto Quit:** optionally enable for selected rarely used apps. Exclude apps that must keep working in the background.

## Optional extensions

- [GitHub](https://www.raycast.com/raycast/github): pull requests, issues and notifications.
- [Visual Studio Code](https://www.raycast.com/thomas/visual-studio-code): open recent projects.
- [Brew](https://www.raycast.com/nhojb/brew): manage Homebrew packages.
- [Kill Process](https://www.raycast.com/rolandleth/kill-process): inspect and quit processes.
- [Coffee](https://www.raycast.com/mooxl/coffee): keep your Mac awake when needed.
- [Speedtest](https://www.raycast.com/tonka3000/speedtest): check your connection.

## Move your own setup

Use Raycast's Export Settings & Data and Import Settings & Data commands for its supported .rayconfig format. Review exported data before sharing. This Markdown guide is not a .rayconfig file.
